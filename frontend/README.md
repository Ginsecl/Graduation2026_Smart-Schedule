# SmartSchedule Frontend

智能个人日程管理系统前端，Vue 3 + TypeScript + Element Plus。

## 快速开始

详细文档请查看项目根目录的 [README.md](../README.md)

## 安装

```bash
npm install
```

## 开发

```bash
npm run dev
```

访问 http://localhost:3000

## 构建

```bash
npm run build
```

## 技术栈

- Vue 3.4
- TypeScript
- Vite 5
- Element Plus 2.6
- Pinia
- Vue Router 4
- ECharts 5.5
